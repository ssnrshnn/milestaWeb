Pertanyaan umum

Di mana dataku disimpan?

Hanya di perangkatmu — Milesta tidak punya akun dan tidak punya server sendiri. Itu juga berarti: jika kamu menghapus aplikasinya, jurnalmu ikut hilang, jadi simpanlah cadangan: ekspor cadangan kapan saja, atau aktifkan cadangan bulanan otomatis di Pengaturan.

Bagaimana cara mencadangkan jurnalku?

Pengaturan → Data → Ekspor Cadangan membuat satu file berisi semua tonggak, foto, dan kategori. Kamu juga bisa mengaktifkan Cadangan bulanan otomatis; salinannya disimpan di aplikasi File (Di iPhone Saya → Milesta).

Bagaimana cara pindah ke iPhone baru?

Ekspor cadangan di perangkat lama, kirim filenya ke perangkat baru (lewat AirDrop atau aplikasi File), instal Milesta, lalu buka Pengaturan → Data → Impor Cadangan.

Rangkumanku belum muncul.

Rangkuman mencakup periode yang sudah selesai: rangkuman Juni muncul pada 1 Juli, rangkuman 6 bulanan pada 1 Januari dan 1 Juli, dan Kilas Balik tahunan pada 1 Januari.

Bagaimana cara membatalkan Premium?

Langganan dikelola oleh Apple: Pengaturan → Apple ID kamu → Langganan → Milesta → Batalkan Langganan. Tonggakmu tetap bisa diakses sepenuhnya di paket gratis.

Kunci Face ID tidak muncul lagi.

Kunci aktif saat aplikasi masuk ke latar belakang dan saat aplikasi dibuka. Jika aplikasi tampak tidak terkunci, iOS mungkin masih membiarkannya aktif — geser aplikasi untuk menutupnya atau kunci ponselmu agar kuncinya aktif kembali.
